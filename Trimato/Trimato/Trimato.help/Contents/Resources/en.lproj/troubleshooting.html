Trimato Help

Resolve common problems

A clip is offline

  1. Select the source clip in Project.
  2. Choose Relink Clip from Actions or activate Relink Media in Inspector.
  3. Select the source file and activate Open.

Export Project is unavailable

  • Add at least one clip to the timeline.
  • Set both In and Out points with In earlier than Out, or clear both points.
  • Wait for the current export to finish or cancel it.

Project Settings does not accept a custom format

  • Enter even width and height values from 2 through 8,192 pixels.
  • Enter a frame rate from 1 through 240 frames per second. Standard fractional rates such as 23.976 and 29.97 are allowed.
  • Use Automatic from First Clip if the first primary timeline clip should establish the project format.

A clip has black space around it

Trimato uses proportional Fit so the complete source remains visible without stretching or automatic cropping. A vertical or narrower source in a landscape project is pillarboxed on the left and right. A wider source is letterboxed above and below. Select the clip and read Project Fit in the Inspector for its project conversion.

A project cannot export offline media

A playback proxy is not a replacement or backup for its original source. Relink every offline source used by the timeline, then choose Export Project again.

Blade at playhead is unavailable

Move the project playhead inside a timeline clip, away from its beginning or end, then activate Blade at playhead again.

Clip Could Not Be Trimmed appears

Command-[ and Command-] require the shared project playhead to be inside the announced direct-edit clip, away from its beginning and end. Use Command-Option-Up Arrow or Command-Option-Down Arrow from Editor to confirm the active track and clip, move the playhead inside that clip, then try the trim again. The dialog is named Clip Could Not Be Trimmed and explains whether the start or end could not be changed.

A cutaway cannot be added

  • Move the project playhead so the complete cutaway fits before the project end.
  • Choose a position that does not overlap another cutaway.

Clear playback proxies

Playback proxies are compatible editing copies created only when macOS cannot play an original directly. Settings reports these proxies, not every temporary file Trimato uses.

  1. Open Trimato Settings.
  2. Read Storage used and Proxy files in Playback proxy storage.
  3. Activate Refresh storage usage if you want Trimato to read the folder again.
  4. Activate Clear proxies not used recently to remove proxies not used in the last seven days, or activate Clear all playback proxies to remove every proxy not required by an open project or editor.
  5. Confirm the action.

These commands leave original media, Trimato projects, completed exports, and temporary renders unchanged. Trimato recreates a cleared proxy when it is next needed, provided the original remains available. Learn more about playback proxies and temporary renders.
