Trimato Help.

Resolve common problems

Relink an offline source

  1. Select the source in Project Source.
  2. Choose Relink Media from Actions or its context menu.
  3. Select the source file and choose Open.

Project export requires every source used by the timeline. Relink missing sources before exporting.

Enable Export Project

  • Add at least one clip to the timeline.
  • Set In before Out, or clear both points for the full project.
  • Finish or cancel an export already running.

Correct a custom project format

Enter even Width and Height values from 2 through 8,192 pixels and a Frame rate from 1 through 240 fps. Fractional frame rates such as 23.976 and 29.97 are accepted.

Choose Automatic from First Clip to use the first video placed on the primary timeline as the project format.

Review black space around a clip

Fit scales the complete source proportionally into the project frame. Narrower sources have black space at the sides; wider sources have black space above and below. Focus the clip and press Command-I to review Project Fit.

Recover a project preview

Choose Show Preview Error and read the reported problem. After correcting it, choose Retry Preview. If a transition caused the failure, Remove Transition is also available.

Review Spatial Audio output

Choose Preserve Spatial Audio and a compatible QuickTime format in Export. Compare the result with the original in the same player and on the same output device. Players can use the included stereo alternative.

For a stereo mix including other audio processing, choose High-quality Stereo.

Review Spatial Audio choices.

Choose HDR or standard video

To retain HDR, turn on Preserve HDR in Settings > Video and choose HEVC or ProRes. MP4 for smaller files (H.264) converts HDR to standard video automatically for projects and clips.

Other H.264 exports from Trim a Clip convert automatically. For other project formats requiring SDR, turn Preserve HDR off.

Review HDR export settings.

Split or trim a clip

To use Blade at Playhead, move the project playhead inside a clip, away from its start and end, then press Command-B.

If Clip Could Not Be Trimmed appears, select the intended track with Command-Option-Up Arrow or Command-Option-Down Arrow in Editor. Move the playhead inside the targeted clip, then use Command-[ for its start or Command-] for its end.

Place a cutaway

Choose a position with enough space for the complete cutaway before the project end and between other cutaways.

Clear cached media

Choose Settings > Storage to review usage and choose a cleanup command. Confirm the cleanup. Trimato recreates cleared analysis and playback proxies from the original media when needed.

Review cache cleanup options.

Report a problem

Include the Trimato and macOS versions, media type, steps leading to the problem, expected result, and actual result. Identify the control or command involved. For an issue with assistive technology, include its name and relevant settings.
