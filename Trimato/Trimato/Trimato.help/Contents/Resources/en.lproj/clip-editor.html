Trimato Help

Edit a clip

Open the Clip Editor

  • Activate Trim a Clip in the Trimato welcome window, select one audio or video file in the Open dialog, and activate Open to begin a standalone edit without creating a project.
  • Select a source clip and choose Open Clip Editor from Actions.
  • Activate a timeline clip or cutaway to open that instance in the Clip Editor.
  • Open an audio or video file with Trimato from Finder to use a standalone Clip Editor.

Continue after a standalone edit

  • Close the standalone Clip Editor window to return to the Trimato welcome window.
  • Activate Create Project from Clip, choose File > Create Project from Clip, or press Command-R to create a new project from the current edited ranges. Trimato closes the standalone editor and opens the new project workspace.

Edit audio against its waveform

An audio clip shows its waveform and playhead. Use the playhead, timecode, markers, playback controls, and edit commands. Left Arrow and Right Arrow move in 1/30-second steps and play a short audio preview.

Delete or trim material

  • Activate Delete Selection or press Delete to remove the marked section.
  • Choose Edit > Trim Start to Playhead or press Command-[ to remove material before the playhead.
  • Choose Edit > Trim End from Playhead or press Command-] to remove material after the playhead.

Update an existing edit

When editing a timeline clip or cutaway from a project, activate Update Clip to apply the current edit to that timeline item.

Add the edit to the project

Use Append to Timeline, Insert and Split, or Insert and Overwrite with audio or video. Video clips also provide Insert on Top because a cutaway supplies picture. If both In and Out points are set, the placement uses that marked section. Otherwise, it uses the complete current edit.

When a video clip contains audio, use the Audio Only menu to append its audio to a track, insert it at the project playhead, or insert and overwrite. Add Audio Only to Track lists audio tracks and can create a named audio track. These commands add sound without adding picture.

Use New Track from Video or New Track from Audio to create a named track and append the current edit. The same commands are available from a source clip's Actions menu and context menu in Project Source.

Press Option-E to open Add to Track. Choose a track, then choose Append to Selected Track. To create a track, enter a New Track Name and choose Create Audio Track and Append or Create Video Track and Append.

Apply clip filters

Video choices are Brightness and Contrast, Color Adjustment, Black and White, Sharpen, Reduce Video Noise, and Crop and Orientation. Audio choices are Tone, Reduce Background Noise, Even Out Volume, and Match Loudness. Basic Gain remains in the Audio group. Existing EQ, high-pass, and low-pass settings appear as Tone.

Filters run in the order shown. Choose Edit Filter to change one, Reset to restore its starting values, or Remove to delete it. A disabled filter remains in the list but does not change the clip.
