Trimato Help

Edit a clip

Open the Clip Editor

  • Activate Trim a Clip in the Trimato welcome window, select one video in the Open dialog, and activate Open to begin a standalone edit without creating a project.
  • Select a source clip and choose Open Clip Editor from Actions.
  • Activate a timeline clip or cutaway to open that instance in the Clip Editor.
  • Open a video with Trimato from Finder to use a standalone Clip Editor.

Continue after a standalone edit

  • Close the standalone Clip Editor window to return to the Trimato welcome window.
  • Choose File > Create Project from Clip to create a new project from the current edited ranges. Trimato closes the standalone editor and opens the new project workspace.

Mark a section

  1. Move the playhead to the beginning of the section.
  2. Activate Mark In or press I.
  3. Move the playhead to the end of the section.
  4. Activate Mark Out or press O.

Delete or trim material

  • Activate Delete Selection or press Delete to remove the marked section.
  • Choose Edit > Trim Start to Playhead or press Command-[ to remove material before the playhead.
  • Choose Edit > Trim End from Playhead or press Command-] to remove material after the playhead.

Update an existing edit

When editing a timeline clip or cutaway from a project, activate Update Clip to apply the current edit to that timeline item.

Add the edit to the project

Use Append to Timeline, Insert and Split, Insert and Overwrite, or Insert on Top. If both In and Out points are set, the placement uses that marked section. Otherwise, it uses the complete current edit.

Export a standalone clip

  1. Set both In and Out points to export a marked section, or clear both to export the complete current edit.
  2. Activate Export Clip or press Command-E.
  3. In the Export Clip dialog, enter a filename and choose a location.
  4. Choose Original format, H.264 MP4, HEVC MP4, H.264 QuickTime movie, HEVC movie, ProRes 422 LT movie, ProRes 422 movie, ProRes 422 HQ movie, M4A AAC audio, M4A Apple Lossless audio, FLAC audio, WAV audio at 16-bit, or WAV audio at 24-bit.
  5. Activate Export.
  6. Read Export progress in the progress dialog. Activate Cancel Export to stop.
