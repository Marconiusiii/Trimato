Trimato Help

Edit a clip

Open the Clip Editor

  • Activate Trim a Clip in the Trimato welcome window, select one audio or video file in the Open dialog, and activate Open to begin a standalone edit without creating a project.
  • Select a source clip and choose Open Clip Editor from Actions.
  • Activate a timeline clip or cutaway to open that instance in the Clip Editor.
  • Open an audio or video file with Trimato from Finder to use a standalone Clip Editor.

Continue after a standalone edit

  • Close the standalone Clip Editor window to return to the Trimato welcome window.
  • Activate Create Project from Clip, choose File > Create Project from Clip, or press Command-R to create a new project from the current edited ranges. Trimato closes the standalone editor and opens the new project workspace.

Mark a section

  1. Move the playhead to the beginning of the section.
  2. Activate Mark In or press I.
  3. Move the playhead to the end of the section.
  4. Activate Mark Out or press O.

Edit audio against its waveform

An audio-only clip displays a static waveform in the viewer with a visible playhead that follows playback and seeking. The waveform is a visual overview and is hidden from VoiceOver. The standard playhead, timecode, markers, transport controls, and edit commands remain the operable controls. Left Arrow and Right Arrow move through audio in 1/30-second editing steps with audible scrub feedback.

Delete or trim material

  • Activate Delete Selection or press Delete to remove the marked section.
  • Choose Edit > Trim Start to Playhead or press Command-[ to remove material before the playhead.
  • Choose Edit > Trim End from Playhead or press Command-] to remove material after the playhead.

Update an existing edit

When editing a timeline clip or cutaway from a project, activate Update Clip to apply the current edit to that timeline item.

Add the edit to the project

Use Append to Timeline, Insert and Split, or Insert and Overwrite with audio or video. Video clips also provide Insert on Top because a cutaway supplies picture. If both In and Out points are set, the placement uses that marked section. Otherwise, it uses the complete current edit.

Press Option-E to open Add to Track. Choose an existing compatible track with the native Track picker, then activate Append to Selected Track. To create a track, enter a New Track Name and activate Create Audio Track and Append or Create Video Track and Append. Creating the track, preserving the edited range and audio settings, and appending the clip are one undoable operation.

Export a standalone clip

  1. Set both In and Out points to export a marked section, or clear both to export the complete current edit.
  2. Activate Export Clip or press Command-E.
  3. In the Export Clip dialog, enter a filename and choose a location.
  4. For video, choose H.264 MP4, HEVC MP4, H.264 QuickTime movie, HEVC movie, ProRes 422 LT movie, ProRes 422 movie, ProRes 422 HQ movie, or an audio format. For audio-only media, choose M4A AAC audio, M4A Apple Lossless audio, FLAC audio, WAV audio at 16-bit, or WAV audio at 24-bit. Original format also appears when macOS can pass through the source container and codec.
  5. Activate Export.
  6. Read Export progress in the progress dialog. Activate Cancel Export to stop.
