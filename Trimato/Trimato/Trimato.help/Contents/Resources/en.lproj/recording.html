Trimato Help

Record with Voicer and Describer

Choose a microphone and playback device in Settings > Audio. Use Record Test and Play Test to check the recording.

Voicer

  1. Move the Editor playhead to the insertion point and press Shift-Command-V.
  2. Set the clip name and insertion time.
  3. Turn Record on, wait for the recording cue, and speak. Turn Record off to finish.
  4. Use Play take to hear the recording alone or Play with show to hear it at the insertion point with the project audio.
  5. Choose Add to Project. The take becomes an audio clip on a Voice Over track.

Open the clip in Audio Clip Editor to edit it. Move or trim it with the usual timeline controls. Overlapping takes use separate tracks.

Describer

Describer and Voicer open in their own tool windows. Command-W closes the tool and returns to the project. Settings and Command-S remain available while the tool is open.

Mark an In and Out point in the Editor and press Shift-Command-D. Describer shows the video during recording and playback with the show. Adjust the In and Out times as needed, then record a description. Enter seconds or timecode such as 00:01:23.450; times display as hours, minutes, seconds, and milliseconds.

Type description text to create an entry on the Description Transcript track. Record a take to create a clip on an Audio Description track. You can save text, audio, or both.

A take that extends beyond the Out point keeps its full length for playback and saving. Choose Speed up to fit or Trim at Out to shorten it to the marked range. Speed up to fit preserves pitch. A shorter take keeps its original length.

Turn on Audio Ducking to lower other project audio while an Audio Description clip plays. Audio Ducking Amount and Fade time appear when it is on. The default is -5 dB with a 0.25-second fade before and after each description. Changes apply automatically to preview playback and project export. Turning it off keeps the chosen amount for later use. Voice Over clips do not trigger ducking.

Adjust a recorded voice

Open the Voice tab in Describer or Voicer. Set Dialogue reference In and Dialogue reference Out to a passage of clear show dialogue. These fields are separate from the recording markers. Use Play reference to hear the passage, then choose Match voice loudness to show. Several seconds of dialogue give a more useful reference than a brief word. Added narration is excluded from the reference.

Turn on Even out voice to reduce differences between louder and quieter words. Adjust Voice level to raise or lower the result. Use Play take or Play with show to hear the adjustments. Remove match removes loudness matching; Reset voice adjustments also turns off voice leveling and resets Voice level.

Choose Apply voice settings to the named track to adjust its existing recorded clips. Each clip is measured separately. Add to Project saves the current take with its voice adjustments. The original recording is kept, and the adjustments are used for project playback and export.

For recordings already in the project, open the audio clip in Audio Clip Editor and select its Voice tab. Use Update Clip to keep changes to that clip, or Apply voice settings to the named track to update existing narration on that track. Undo reverses an applied change.

Save and export

Save the project before adding a recording. Accepted recordings are stored in the Recordings folder alongside the Trimato project. Keep that folder with the project when moving or copying it. Cancel discards the current unsaved take.

Choose Timeline > Export Description Transcript to export the text separately. During project export, select Export description transcript (WebVTT) to write a timed description file alongside the exported media. Caption export remains a separate choice. Description text never appears on the video.
