Trimato Help.

Record with Voicer and Describer

Use Voicer to add narration at the playhead. Use Describer to record audio description for a marked passage and write a timed description transcript.

Set up recording

Choose Settings > Audio to select your microphone, input channel, recording quality, and playback device. Use Record Test and Play Test to check the result.

Allow microphone access when macOS asks. To change permission, open System Settings > Privacy & Security > Microphone and enable Trimato.

Record narration

  1. Move the Editor playhead to the insertion point and press Command-Shift-V.
  2. Set the clip name and Insert at time in Voicer.
  3. Turn Record on and speak after the start cue. Turn Record off to finish.
  4. Choose Play Take to review the recording, or Play with Primary Audio to review it in context.
  5. Choose Add to Project to place the recording on a Voice Over track.

Use Voicer’s playback and voice adjustments.

Record audio description

  1. Set In and Out in Editor around the passage, then press Command-Shift-D.
  2. Review the passage with Play from In to Out.
  3. Enter description text, record a take, or prepare both. The main Editor shows the video.
  4. Review the take with Play Take or Play with Primary Audio.
  5. Choose Add to Project. Text becomes a Description Transcript entry; recorded audio becomes an Audio Description clip.

Audio Ducking lowers other project audio during description clips.

Set description timing, ducking, and voice adjustments.

Adjust a recorded voice

Open Voice Adjustments in Voicer or Describer. Choose a passage of Primary Audio dialogue with Dialogue reference In and Dialogue reference Out. Use Play reference to review it, then choose Match voice loudness to Primary Audio.

Turn on Even out voice to reduce differences between louder and quieter words. Use Voice level to adjust the overall level, then review the result with Play Take or Play with Primary Audio.

For a recording already on the timeline, open it in Audio Cutting Board and use the Voice tab. Choose Update Clip to save changes to that clip. Apply voice settings to the named track updates existing recordings on that track.

Save recordings and transcripts

Accepted recordings are stored in the Recordings folder beside the saved project. Keep that folder with the project when moving or copying it.

Choose Timeline > Export Description Transcript to save the text. In Export Project, Export description transcript (WebVTT) saves a timed transcript beside the exported media.
