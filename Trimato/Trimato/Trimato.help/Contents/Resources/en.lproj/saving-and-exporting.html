Trimato Help

Save and export

Save the project

  • Choose File > Save or press Command-S.
  • Choose File > Save As or press Shift-Command-S to save another project package.
  • Choose File > Close Project or press Shift-Command-W to close the project.

Choose the export range

  • Set both In and Out points in the project Editor to export that range.
  • Clear both In and Out points to export the complete project.
  • Place In earlier than Out.

Understand the exported project frame

Every video export uses the project's resolution and frame rate. Mixed source dimensions are proportionally fitted without stretching or automatic cropping. Narrower sources are pillarboxed, wider sources are letterboxed, and unused parts of the project frame are black.

The project frame rate is the export cadence. Trimato omits source frames when converting from a higher rate and repeats source frames when converting from a lower rate. This does not change clip speed or audio duration. Optical-flow frame generation is not currently applied.

When most material uses one rate, choosing that rate for the project usually preserves its original motion cadence. For example, a 30 fps project is a practical match for predominantly 30 and 60 fps material, while a 24 fps project preserves the cadence of predominantly 24 fps material.

Understand which media export uses

Playback proxies are used for responsive preview and editing, not as the final-quality sources for a project export. Trimato returns to the original source files and applies the source ranges, timeline arrangement, cutaways, audio choices, project resolution, and project frame rate saved in the project.

If macOS cannot use an original source directly in the final composition, Trimato creates a temporary full-resolution ProRes render intermediate from that original. Trimato uses the intermediate to complete the selected output and removes it after export.

Keep every original source used by the timeline available. A cached proxy does not make an offline original available for final export.

Export the project

  1. Choose File > Export Project or press Command-E.
  2. In the Export Project dialog, enter a filename, choose a location, and choose H.264 MP4, HEVC MP4, H.264 QuickTime movie, HEVC movie, ProRes 422 LT movie, ProRes 422 movie, ProRes 422 HQ movie, M4A AAC audio, M4A Apple Lossless audio, FLAC audio, WAV audio at 16-bit, or WAV audio at 24-bit.
  3. Activate Export.
  4. Read Export progress in the progress dialog. Activate Cancel Export to stop.

Export a standalone clip

  1. Open the clip in a standalone Clip Editor.
  2. Set both In and Out points to export a range, or clear both to export the complete edit.
  3. Activate Export Clip or press Command-E.
  4. In the Export Clip dialog, enter a filename, choose a location and format, then activate Export.
  5. Read Export progress in the progress dialog. Activate Cancel Export to stop.

Check an export result

When export finishes, Trimato announces “Export complete.” If Trimato notifications are allowed, macOS sends a system notification containing the exported filename. Open the saved movie or audio file from its chosen location.

Review export notification permission

Choose Trimato > Settings and read Export Notifications. If the permission is Not requested, activate Allow Export Notifications. If the permission is Not allowed, open System Settings, choose Notifications, choose Trimato, and turn on Allow Notifications.
