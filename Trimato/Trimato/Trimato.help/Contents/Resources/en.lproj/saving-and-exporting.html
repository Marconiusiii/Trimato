Save and export

Save your project for the next editing session, or export the finished cut as video, audio, captions, or a web player.

Save the project

  • Command-S or File > Save saves project changes.
  • Command-Shift-S or File > Save As saves another project package.
  • Command-Shift-W or File > Close Project closes the project.

Apply drafts with Add or Update in their editors before saving. When closing with unsaved changes, choose Save, Don’t Save, or Cancel. Don’t Save returns to the saved project state; Cancel returns to editing.

Review Auto-Save, quitting, and project media storage.

Choose the range

Set both In and Out in Editor to export a range, with In before Out. Clear both to export the complete timeline.

Choose an audio track and turn on Mute Track to silence it in preview and export. Turn it off to restore its sound.

Export a project

  1. For written captions, choose Timeline > Captions > Finalize Captions and resolve any passages identified in the results.
  2. Press Command-E or choose File > Export Project.
  3. Enter a filename and choose a location and format.
  4. For captions, turn on Include captions and choose Burn Captions into Video, WebVTT Sidecar File, or SRT Sidecar File.
  5. Choose Export.

Burn Captions into Video places captions in the picture. Sidecar options save a caption file beside the media with a matching filename. Include captions starts off for ordinary exports.

Choose Cancel Export to stop. When Export complete appears, open the saved media at the chosen location. A completion sound plays when enabled in Settings > General. macOS sends a notification with the filename when export notifications are allowed.

Choose a video format

  • MP4 for broad compatibility (H.264) suits a wide range of players.
  • MP4 for smaller files (H.264) uses stronger compression and converts HDR to standard video automatically. For spatial recordings, choose High-quality Stereo.
  • HEVC compresses video efficiently for compatible players.
  • ProRes provides larger files suited to further editing.

Video exports use the project’s dimensions and frame rate. Fit scales each complete source proportionally into that frame, filling unused space with black. Frame-rate conversion keeps clip speed and audio duration.

Set the project format in File > Project Settings. A 4K source in a 1080p project exports at 1080p; a 120 fps source in a 30 fps project exports at 30 fps.

Preserve HDR or export standard video

HDR retains a recording’s extended brightness and color. To export HDR:

  1. Turn on Preserve HDR in Settings > Video.
  2. Choose a compatible HEVC or ProRes format in Export.

HEVC HDR exports use 10-bit video with Dolby Vision metadata. ProRes retains HLG HDR. Supported HDR output includes video filters, transitions, and burned-in captions.

For standard dynamic range, or SDR, turn Preserve HDR off. MP4 for smaller files (H.264) converts automatically for both projects and clips. Other H.264 exports from a standalone Cutting Board also convert automatically.

Same as original keeps the source format for supported standalone clips. Picture quality also depends on source quality, filters, project dimensions, and the chosen codec.

Clip processing retains the source sample rate. A project mixes at the highest sample rate among its audio sources. Mixed project exports are stereo; standalone mono clips can remain mono.

For an audio mix, press Command-E, choose Audio only from Export type, then select an audio format. The mix includes track levels, fades, master volume, and description ducking.

Export iPhone Spatial Audio

  1. Choose Export Project or Export Clip.
  2. Set Audio to Preserve Spatial Audio or High-quality Stereo.
  3. Choose a compatible Format, then export.

Preserve Spatial Audio uses compatible QuickTime movies with spatial channels and a stereo playback alternative. Supported volume changes, mute, fades, Cross Fade, and Fade Out/In retain spatial sound.

Ordered cuts from one recording with unchanged audio keep the original encoding. Combining recordings or applying supported audio changes uses uncompressed audio and produces larger files.

Choose High-quality Stereo for other audio effects, voice adjustments, pan, balance, width, channel routing, ducking, or mixing spatial and ordinary audio. Preview uses stereo for those adjustments.

Trimato remembers the Audio choice. Review the finished export in the intended player and output device.

Export a standalone clip

  1. Open a clip with Trim a Clip in the welcome window.
  2. Edit it in Cutting Board. Set In and Out for a range, or clear both for the complete edit.
  3. Choose Export Clip or press Command-E.
  4. Enter a filename, choose a location and format, then choose Export.

Export captions

  1. Choose Timeline > Captions > Finalize Captions for written passages and resolve any drafts.
  2. Choose Timeline > Captions > Export Captions.
  3. Choose WebVTT, SRT, or Plain Text, enter a filename, then choose Export.

With project In and Out set, captions use that range and their exported times begin at zero. Clear both points for the complete caption track.

Plain Text begins with the project title and places each caption in its own paragraph. WebVTT and SRT include cue times.

Export a frame

Place the project playhead on the frame, then press Command-Shift-P or choose File > Export Frame. Choose Include captions if wanted, then Continue and save the PNG.

The image uses the project’s full dimensions, picture edits, effects, and titles at the captured time. Color is converted to SDR.

Export web video

  1. Place the playhead on the poster frame, within the export range.
  2. Press Command-Shift-E or choose File > Export Web Video.
  3. Review Poster frame and Include captions. Choose the caption language when including captions.
  4. Choose Continue, select a destination folder, then choose Export.

The Web Video folder contains video.mp4, poster.png, embed.txt, and captions.vtt when captions are included. A numbered folder is created when an earlier export has the same name.

Upload the files to your site and paste the HTML from embed.txt into your page’s HTML editor. Adjust the file paths to match their uploaded locations. The player includes native controls, a poster, a download link, and the chosen caption track. Video uses H.264 MP4 and SDR color.

Serve captions from the player’s website or configure cross-origin access for them. Review the published video, captions, and audio description in the browsers your audience uses.

YouTube chapters

  1. Press Option-M in Editor to add a Chapter. Edit its title in the Markers track.
  2. Add at least three Chapters, starting at 00:00. Allow at least 10 seconds for each, including the last.
  3. In Export Project, keep Export YouTube Chapters checked.
  4. Open the chapters.txt companion file and paste its timestamps and titles into the video’s description in YouTube Studio.

For a range export, chapter times begin at the exported movie’s start. A range beginning inside a Chapter uses that title at 00:00, followed by Chapters within the range.

Correct any chapter timing identified during export, or clear Export YouTube Chapters to export the movie alone. Export Web Video can also save chapters.txt in its output folder.

Keep sources available

Project export reads original source files and applies the saved edits, mix, and project format. Keep every source used by the timeline available. Relink missing sources in Project Source before exporting.

Choose an export filename distinct from source media. If conversion is needed, Trimato prepares temporary export media and removes it when export ends.
