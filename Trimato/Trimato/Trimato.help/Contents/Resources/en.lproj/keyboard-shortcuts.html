Trimato Help

Keyboard shortcuts

Playback and navigation

ShortcutCommand
SpacePlay or pause
JPlay backward; press again to increase speed
KPlay or pause
LPlay forward; press again to increase speed
Left ArrowMove backward one frame
Right ArrowMove forward one frame
Command-Left ArrowPrevious marker or edit point
Command-Right ArrowNext marker or edit point
Command-Up ArrowGo to beginning
Command-Down ArrowGo to end
CCopy the current timecode

Markers and clip editing

ShortcutCommand
ISet or replace the In point
OSet or replace the Out point
DeleteDelete the marked section in Clip Editor or the selected project timeline item
Command-[Trim start to playhead
Command-]Trim end from playhead
Command-UUpdate the current timeline clip or cutaway edit

Project timeline

ShortcutCommand
Command-BBlade at the project playhead
Option-Command-Left ArrowMove the selected timeline clip earlier
Option-Command-Right ArrowMove the selected timeline clip later

Place a clip

ShortcutCommand
EAppend to Timeline
WInsert and Split
DInsert and Overwrite
QInsert on Top with Source Audio
Option-QInsert on Top over Primary Audio

Files and export

ShortcutCommand
Command-SSave project
Shift-Command-SSave project as
Shift-Command-IImport media
Command-EExport the active project or standalone clip
Shift-Command-WClose project
