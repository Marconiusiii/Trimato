Voicer

Add narration at a chosen position in the project.

Record a take

  1. Move the Editor playhead to the insertion point and press Command-Shift-V.
  2. In Recording, set the clip name and Insert at time.
  3. Turn Record on and speak after the start cue. Turn Record off to finish.
  4. Choose Play Take to review the recording alone, or Play with Primary Audio to hear it in context.
  5. Choose Add to Project to place the take on a Voice Over track.

The main Editor shows the video. Project time gives the current position during project playback and recording.

Play Project from Insertion Point reviews existing project audio from Insert at through the end. Choose Stop Playback to stop.

Set your microphone, input channel, recording quality, and playback device in Settings > Audio. Use Record Test and Play Test to check the setup.

Set up recording input and playback.

Place recordings

Each take starts at Insert at on a track with Magnetic off. Overlapping takes use separate tracks. If an earlier recording track is magnetic, Trimato uses another available absolute track or creates one.

Open a saved recording in Audio Cutting Board to trim it.

Manage track timing and Magnetic.

Adjust the voice

Select Voice Adjustments. Set Dialogue reference In and Dialogue reference Out around several seconds of clear Primary Audio dialogue. Choose Play reference, then Match voice loudness to Primary Audio.

Even out voice reduces differences between louder and quieter words. Voice level adjusts the overall level. Use Play Take or Play with Primary Audio to review the result.

Remove match removes loudness matching. Reset voice adjustments clears matching, turns off leveling, and resets Voice level.

Apply voice settings to the named track updates existing recordings on that track, measuring each clip separately. Add to Project saves the current take with its voice adjustments.

To adjust a recording already in the project, open it in Audio Cutting Board and use its Voice tab. Choose Update Clip to save changes to that clip.

Save and close

Save the project before adding a recording. Accepted takes are stored in Recordings beside the project. Keep this folder with the project when moving or copying it.

If Choose Project Media Folder opens, select the folder containing the saved project and choose Choose Folder.

Choose Cancel, press Escape, or choose File > Close Voicer to close the tool. If a draft is unfinished, choose whether to discard it or continue editing. Cancel discards the current unsaved take.
