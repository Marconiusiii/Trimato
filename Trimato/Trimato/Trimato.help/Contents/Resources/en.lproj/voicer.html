Voicer

Choose a microphone and playback device in Settings > Audio. Use Record Test and Play Test to check the recording.

Choose System Default to use the current macOS input or playback device, or select a specific device. Input and playback can use different devices. Choose the input channel for a multi-channel interface. Recordings retain the input sample rate and use the selected recording quality.

Voicer opens in the full-height tool pane on the right. Press Command-4 to move keyboard and VoiceOver focus into it. Escape or Command-W closes the pane; unfinished changes require a discard decision. The main Editor shows the video while you record or use Play with Primary Audio. Choose Play project range to review from the insertion point before recording.

  1. Move the Editor playhead to the insertion point and press Shift-Command-V.
  2. Set the clip name and insertion time.
  3. Turn Record on and begin speaking after the start cue. Turn Record off to finish; the stop cue sounds before the microphone is released.
  4. Use Play take to hear the recording alone or Play with Primary Audio to hear it at the insertion point with the project audio.
  5. Choose Add to Project. The take becomes an audio clip on a Voice Over track, and the tool pane closes.

Open the clip in Audio Clip Editor to edit it. Move or trim it with the usual timeline controls. Overlapping takes use separate tracks.

Keep recordings at their assigned times

Each Voice Over recording starts at its requested project time. New recordings use a track with Magnetic off. If a previous recording track has been made magnetic, the new take uses an available absolute track or creates one. Overlapping takes use separate tracks.

With Magnetic off, replacing, trimming, deleting, or moving one recording leaves the other recordings at their assigned times. Enabling Magnetic in Timeline asks for confirmation before moving the first clip to zero and packing the rest together without gaps. One Undo restores the setting and exact original positions. Learn about Magnetic and Move To Playhead.

Adjust a recorded voice

Expand Voice Adjustments in Describer or Voicer to adjust the recorded voice. Recording and take playback controls remain available above this section. Set Dialogue reference In and Dialogue reference Out to a passage of clear Primary Audio dialogue. These fields are separate from the recording markers. Use Play reference to hear the passage, then choose Match voice loudness to Primary Audio. Several seconds of dialogue give a more useful reference than a brief word. Added narration is excluded from the reference.

Turn on Even out voice to reduce differences between louder and quieter words. Adjust Voice level to raise or lower the result. Use Play take or Play with Primary Audio to hear the adjustments. Remove match removes loudness matching; Reset voice adjustments also turns off voice leveling and resets Voice level.

Choose Apply voice settings to the named track to adjust its existing recorded clips. Each clip is measured separately. Add to Project saves the current take with its voice adjustments. The original recording is kept, and the adjustments are used for project playback and export.

For recordings already in the project, open the audio clip in Audio Clip Editor and select its Voice tab. Use Update Clip to keep changes to that clip, or Apply voice settings to the named track to update existing narration on that track. Undo reverses an applied change.

Save and export

Save the project before adding a recording. Accepted recordings are stored in the Recordings folder alongside the Trimato project. Keep that folder with the project when moving or copying it. Cancel discards the current unsaved take.

If Choose Project Media Folder opens, select the folder containing the saved Trimato project, then choose Choose Folder. This can be needed after Save As to a different location.

Choose Timeline > Export Description Transcript to export the text separately. During project export, select Export description transcript (WebVTT) to write a timed description file alongside the exported media. Caption export remains a separate choice. Description text never appears on the video.
