Understand the workspace

The project workspace contains four main groups.

Project

Import source clips, create folders, open clips, add clips to the timeline, move clips between folders, and relink offline media.

Editor

Play the assembled project, move the project playhead, set In and Out points, move among edit points, blade the clip beneath the playhead, and check export progress.

Timeline

Review timeline clips in playback order. Open, move, or delete a selected timeline clip. Split instances use lettered names such as Clip01 A and Clip01 B.

Inspector

Read information about the current project, source clip, timeline clip, or cutaway. The first item beneath the Inspector heading identifies the inspected item.
