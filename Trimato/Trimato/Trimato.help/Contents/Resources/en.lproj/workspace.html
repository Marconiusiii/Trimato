Understand the workspace

The project workspace contains three main groups.

Project

Import source clips, create folders, open clips, add clips to the timeline, move clips between folders, and relink offline media.

Editor

Play the assembled project, move the project playhead, set In and Out points, move among edit points, blade the clip beneath the playhead, and check export progress.

Timeline

Choose a video or audio track with the Track picker, then review its clips and transitions in playback order. Current identifies the clip under the shared project playhead. Focusing a clip makes it the target for timeline commands and Get Info; Selected identifies only a clip picked up for movement.

Enter opens the focused clip in Clip Editor. Space picks it up or drops it. On primary tracks, arrows move a picked-up clip through the list. On additional tracks, plain arrows nudge the focused or picked-up clip one project frame without overlapping neighboring clips. Mute Track silences the chosen audio track in preview and export. Split instances use lettered names such as Clip01 A and Clip01 B. Learn about placement, movement, and transitions.

Get Info

Press Command-I to open a separate Get Info window for the focused project source, Editor, timeline clip, transition, or Clip Editor item. The window contains a fixed snapshot, so later project changes do not interrupt VoiceOver navigation inside it.
