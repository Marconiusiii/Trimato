Describer

Record audio description and write a timed transcript for a passage in your project.

Prepare the passage

  1. Set In and Out around the passage in Editor.
  2. Press Command-Shift-D to open Describer.
  3. In Recording, set the clip name and review the In and Out times.
  4. Choose Play from In to Out to review the passage.

Enter times as seconds or timecode, such as 00:01:23.450. The main Editor shows the video during playback and recording.

Choose Settings > Audio to select a microphone, input channel, recording quality, and playback device. Use Record Test and Play Test to check the setup.

Set up recording input and playback.

Write and record

Enter description text to create a Description Transcript entry. Record a take to create an Audio Description clip. Choose Add to Project to save text, audio, or both.

Turn Record on and speak after the start cue. Turn Record off to finish. Project audio stops at Out during recording; finish the take when your description ends.

Use Play Take to review the full recording. Play with Primary Audio reviews it against the marked passage from In to Out.

If a take extends beyond Out, choose Speed up to fit to shorten it while preserving pitch, or Trim at Out to cut it at the boundary. A shorter take keeps its recorded length.

Set audio ducking

Turn on Audio Ducking to lower other project audio during Audio Description clips. Set Audio Ducking Amount and Fade time. Defaults are -5 dB and a 0.25-second fade before and after each description.

The settings apply to project preview and export. Turning Audio Ducking off saves the amount for later use.

Place recordings

Each recording starts at its requested project time on a track with Magnetic off. Overlapping takes use separate tracks. If an earlier recording track is magnetic, Trimato uses another available absolute track or creates one.

Description Transcript entries have their own start and end times.

Manage track timing and Magnetic.

Adjust the voice

Select Voice Adjustments. Set Dialogue reference In and Dialogue reference Out around several seconds of clear Primary Audio dialogue. Choose Play reference, then Match voice loudness to Primary Audio.

Even out voice reduces differences between louder and quieter words. Voice level adjusts the overall level. Use Play Take or Play with Primary Audio to review the result.

Remove match removes loudness matching. Reset voice adjustments clears matching, turns off leveling, and resets Voice level.

Apply voice settings to the named track updates existing recordings on that track, measuring each clip separately. Add to Project saves the current take with its voice adjustments.

To adjust a recording already in the project, open it in Audio Cutting Board and use its Voice tab. Choose Update Clip to save changes to that clip.

Save and close

Save the project before adding a recording. Accepted takes are stored in Recordings beside the project. Keep this folder with the project when moving or copying it.

If Choose Project Media Folder opens, select the folder containing the saved project and choose Choose Folder.

Choose Cancel, press Escape, or choose File > Close Describer to close the tool. If a draft is unfinished, choose whether to discard it or continue editing. Cancel discards the current unsaved take.

Export the transcript

Choose Timeline > Export Description Transcript to save the text separately. In Export Project, turn on Export description transcript (WebVTT) to save a timed transcript beside the exported media.
