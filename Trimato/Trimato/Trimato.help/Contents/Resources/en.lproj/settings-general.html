Trimato Help.

General settings

Choose Trimato > Settings, then General.

Appearance

Set Appearance to System, Light, or Dark. System follows your Mac’s appearance. Choose Accent color to set the color used by controls, waveforms, and selections.

Turn on Show Audio Waveforms to display a static audio overview in Mixer and Audio Cutting Board. This setting starts off and applies across projects.

Saving

Turn on Auto-Save and set Minutes between saves from 1 through 120. The default interval is five minutes. Auto-Save saves changes already added to the project at its current location.

Use Add or Update in an open editor to apply its draft to the project. Save projects and manage media.

Imported files

Set Imported files to Keep in Place, Move to Project, or Ask Each Time. Move to Project transfers media into the project’s Clips folder, then removes the originals after verification and a successful project save.

Sounds

Processing sounds plays a repeating ascending cue during longer actions such as recording preparation and filter preview preparation. Export completion sound plays a short tune after a successful export. Turn each setting on or off to choose the feedback you want.

Marker audio plays a short note when you create a Marker with M or a Chapter with Option-M in Editor. It starts on and pauses during recording.

Export notifications

Export notification access shows the current permission. Choose Allow export notifications to request a system notification with the filename after a successful export.

To change an existing permission, open System Settings > Notifications > Trimato and set Allow Notifications.
