Trimato Manual contents.

General settings

Choose Trimato > Settings, then General.

Appearance

Choose Appearance to follow the system appearance or use a light or dark interface. Choose Accent color to change the accent used by Trimato controls.

Saving

Turn on Auto-Save and set Minutes between saves from 1 through 120. The default interval is five minutes. Auto-Save saves committed changes to an already saved project; it does not apply unfinished edits in another window or ask for a new save location.

Imported files

Choose whether imported media stays at its current location, moves into the project's Clips folder, or prompts you to choose for each import. Moving media removes the originals after the transfer is verified and the project is saved.

Learn about project media and file handling.

Sounds

Processing sounds provide repeated feedback during longer operations. Export completion sound plays after a successful export. Turn either setting off to silence that type of feedback.

Export notifications

Export notification access shows the current permission. Choose Allow export notifications to request a system notification containing the filename after a successful export. If access is not allowed, open System Settings, choose Notifications, select Trimato, and turn on Allow Notifications.
