Trimato Help.

Create projects and organize media

Create a project

  1. Choose New Project in the welcome window.
  2. Enter a Project Name and choose a Project Format.
  3. For a reference length, turn on Use Target Duration and enter seconds.
  4. Choose Next, select a location in Save Project, then choose Create.

The project folder contains the saved .trimato project. Choose File > Project Settings to change the name, format, or target duration later.

Choose a project format

A video project uses one resolution and frame rate for preview and export.

Automatic from First Clip
Uses the displayed dimensions and nominal frame rate of the first video clip placed on the primary timeline.
Custom
Provides Resolution and Frame rate menus. Choose Custom dimensions or Custom frame rate to enter your own values.

Custom dimensions must be even numbers from 2 through 8,192 pixels. Lock aspect ratio starts on: editing Width calculates Height, and editing Height calculates Width. Turn it off to enter each independently. Turning it on locks the current ratio.

Frame rate accepts values from 1 through 240 frames per second. Presets include 23.976, 24, 25, 29.97, 30, 50, 59.94, 60, and 120 fps.

Changing a populated project to Automatic resolves its format from the first primary timeline clip.

Open a project

Choose Open Project to select a saved project, or choose an entry in Recent Projects. Opening the same project brings its window forward.

Trimato works with one project at a time. Creating or opening another closes the current project after reviewing unsaved changes.

Import media

Choose Import Files in Project or press Command-Shift-I. Select audio, video, SRT or WebVTT captions, or folders containing supported files, then choose Open.

Supported video containers include MKV, WebM, TS, MTS, M2TS, VOB, WMV, and FLV. Playback and export depend on the codecs inside each file.

Imported media appears in Project Source. Use a clip’s Actions or context menu to open Cutting Board or place the clip on a track.

Organize folders

Choose New Folder to create a folder. Select a folder and use Actions to import into it, rename it, or remove it. Use a source clip’s Actions > Move Clip command to move it to another project folder or the root.

Choose where media is stored

A project stores editing choices and references to source files. Keep those files available at their saved locations, or gather them into the project folder with Consolidate Clips.

In Settings > General, set Imported files:

  • Keep in Place uses media at its current location. This is the default.
  • Move to Project transfers media into the project’s Clips folder and removes the originals after verification and a successful save.
  • Ask Each Time asks once for each import batch.

Save the project before importing with Move to Project. Use Consolidate Clips to gather media already imported.

Consolidate project media

  1. Save the project and choose File > Consolidate Clips.
  2. Relink any missing sources identified in the window, then run Consolidate Clips again.
  3. Choose Copy Clips to keep the originals, or Move Clips to remove them after verification and a successful save.

Consolidation places imported media and referenced recordings in a Clips folder beside the project. Multiple references to one source share a copy. Keep the project and Clips folder together when moving them in Finder.

If folder access is requested, select the folder containing the project. Moving source files affects other projects that use them.

Choose Cancel to stop consolidation. If removing an original fails after its copy is saved, the result identifies the original that remains.

Relink missing media

Missing sources show Source Missing in Project Source and Timeline Clips. To choose their location:

  1. Open the source clip’s Actions or context menu in Project Source.
  2. Choose Relink Media.
  3. Select the replacement audio or video file, then choose Open.

The replacement must contain the required tracks and be long enough for the saved edits. Relinking updates every timeline use of the source. A disconnected source also becomes available when its original location returns.

Use mixed media

Clips with different dimensions, orientations, and frame rates play and export in the project format. Fit scales the complete source proportionally into the frame. A narrower picture has black space on its sides; a wider picture has black space above and below.

Frame-rate conversion keeps the clip’s playback speed and audio duration. An audio-only section in a video project has black picture; place video above it to supply a picture.

Focus a source or timeline clip and press Command-I. Project Fit and Frame Rate Conversion describe its conversion to the project format.

Choose HDR export settings. Export Spatial Audio.

Playback copies

Trimato plays original media directly when supported by macOS. For other sources, it creates a compatible playback copy called a proxy. Editing uses the proxy; final project export uses the original source.

Review cached and temporary media.

Save and close

Press Command-S to save project changes. Auto-Save in Settings > General saves changes already added to the project at intervals from 1 through 120 minutes. It starts off; the default interval is five minutes.

Press Command-Q to quit. If changes are pending, Save changes before quitting offers:

  • Save and Quit applies pending editor changes, saves the project, and quits.
  • Quit Without Saving discards pending drafts and project changes since the last manual save or Auto-Save.
  • Cancel returns to editing.

Resolve any settings identified during Save and Quit, and stop recording before saving a take. A new Generator draft is placed with Insert and Split at its captured playhead and destination track.

If saving is interrupted or fails, review the reported problem before continuing. Editors whose changes were applied have closed; remaining drafts stay in their editors.

Closing a timeline Cutting Board with Command-W offers Update Clip, Close without Updating, or Cancel when it has pending changes.

Remove clips and media

Choose Remove from Timeline in a clip’s context menu to remove that instance and keep its source in Project Source.

Choose Delete Media to remove a source from the project together with all timeline clips and transitions using it. Review the number of affected clips before confirming. The media file stays at its Finder location.

Use Undo to restore a removal, then save to keep the chosen project state.
