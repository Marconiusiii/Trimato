Trimato Help

Create projects and organize media

Open a project

  • Activate New Project to create a project.
  • Activate Open Project to select a saved Trimato project.
  • Activate a project in Recent Projects to reopen it.

Change project settings

  1. Choose File > Project Settings.
  2. Edit the project name, format, or target duration.
  3. Activate Save Project Settings.

Choose a project format

Every project containing video has one resolution and frame rate. These values define the project frame used for preview and export; they do not modify the original media. An audio-only project does not need a visual format.

Automatic from First Clip
Uses the displayed dimensions and nominal frame rate of the first video clip placed on the primary timeline. Importing a file into the Project Browser does not establish the format, and an audio-only clip does not establish visual dimensions or a frame rate.
Custom
Provides Resolution and Frame Rate menus with common choices. Choose Custom dimensions or Custom frame rate when the project needs values that are not listed.

Custom dimensions must be even numbers from 2 through 8,192 pixels. Lock aspect ratio is on initially: changing Width calculates Height, and changing Height calculates Width. Turn the checkbox off to edit the dimensions independently. Turning it back on locks the current ratio.

A custom frame rate must be from 1 through 240 frames per second. Fractional rates are allowed. Standard menu choices include 23.976, 24, 25, 29.97, 30, 50, 59.94, 60, and 120 fps.

If a populated project is changed to Automatic, Trimato resolves the format from its first primary timeline clip.

Import clips

  1. Activate Import Clips in the Project group or choose File > Import Media.
  2. Select one or more audio or video files.
  3. Activate Open.

Imported clips appear in the Clips section of the project.

Understand non-destructive editing

Trimato does not cut, rewrite, or move an imported source file. Trimming, deleting sections, splitting clips, and arranging the timeline save instructions that identify which source ranges to use and where to use them.

The project package saves these editing instructions and a reference to each source file. It does not contain a copy of the original media. Keep original files available at their saved locations. If a file is moved, renamed, disconnected, or deleted, Trimato may report it as offline until it is relinked.

Understand playback compatibility

Trimato examines the media streams inside a file instead of deciding compatibility from the filename extension alone. Two files with the same extension can use different codecs.

  • If macOS can play and pass through a source, Trimato plays the original and can retain its original file type and codec for an Original format standalone clip export.
  • If macOS can play a source but cannot pass it through, Trimato still plays the original and converts it when exporting.
  • If macOS cannot play a source, Trimato creates a local playback proxy for preview and editing. Audio-only proxies remain audio-only.

Understand playback proxies

Trimato creates a playback proxy only when macOS cannot play an original file directly. A proxy is a compatible editing copy. It does not modify the original and is not used as the final-quality source for project export.

Compatible media can use the original directly, so substantial editing may use no playback proxy storage. Learn what Trimato stores and when it removes temporary media.

Use media with different dimensions and frame rates

A project can contain sources with different file formats, codecs, resolutions, orientations, aspect ratios, and frame rates. Trimato conforms each timeline instance to the project during preview and export while leaving the original file unchanged.

Audio-only clips use the same magnetic primary timeline, markers, trimming, splitting, naming, and ordering tools as video clips. In a video project, an audio-only section produces black picture while its audio plays. A video cutaway can provide picture over that section. Insert on Top is unavailable when the source itself has no video.

For dimensions and orientation, Trimato uses proportional Fit:

  • A vertical or narrower source in a landscape project is centered and pillarboxed with black space on the left and right.
  • A source wider than the project frame is centered and letterboxed with black space above and below.
  • A source with the same aspect ratio is scaled proportionally to the project frame.
  • Trimato does not stretch or automatically crop a source to fill the project frame.

Fit may enlarge a lower-resolution source until one dimension reaches the project boundary. It does not enlarge the source beyond that boundary to remove letterboxing or pillarboxing.

For frame rate, Trimato renders every source at the project cadence. Frames from higher-rate sources are omitted as needed, and frames from lower-rate sources are repeated as needed. Clip speed and audio duration remain unchanged. Trimato does not currently synthesize intermediate frames with optical flow.

Review how a clip fits the project

Select a source clip, timeline clip, or cutaway, then move to the Inspector. When its dimensions, aspect ratio, or frame rate differ from the project, Project Fit and Frame Rate Conversion describe what Trimato will do.

Use project folders

  • Activate New Folder to create a folder.
  • Select a folder and use Actions to import clips into it, rename it, or remove it.
  • Select a source clip and use Actions > Move Clip to place it in the project root or a folder.

Relink an offline clip

  1. Select the offline source clip.
  2. Choose Relink Clip from Actions or activate Relink Media in the Inspector.
  3. Select the source file and activate Open.

Create a generator

In the project Editor, press Command-G or choose Timeline > Generator. Playback pauses and the Generator window captures the current playhead position. Choose Black, Solid Color, Static Gradient, or Silence, then set its parameters and duration in seconds or whole project frames. Silence supports mono and stereo. Video uses the project dimensions and frame rate, or 1920 by 1080 at 30 frames per second if the project format is unresolved.

Choose a compatible Destination Track, or New Track and a name. VoiceOver starts at the Generator heading. Review the generated clip in the Editor after placement. Cancel Preparation stops processing and closes the window without changing the project. Choose Append, Insert and Split, or Insert and Overwrite. For video, Insert on Top in New Video Track creates an additional track at the captured playhead. Insert and Split advances the project playhead to the inserted clip's end. Adding the generator and a new track when requested is one undoable operation.

Generator settings are saved with the project. Internal playback files can be regenerated without an external source file. Open the generated timeline clip in Clip Editor and activate Edit Generator to change its settings or duration. Commit pending clip edits first. Update Generator changes only that instance, preserving other copies.
