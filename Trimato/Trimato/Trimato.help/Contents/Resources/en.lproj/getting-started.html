Trimato Help

Get started with a project

Allow export notifications

  1. On first launch, macOS asks whether Trimato may send notifications.
  2. Activate Allow to receive the exported filename when an export completes.

Create the project

  1. Activate New Project in the Trimato window.
  2. Enter a project name.
  3. Choose Automatic from First Clip or Custom for the project format.
  4. If you choose Custom, enter the width, height, and frame rate.
  5. Optionally turn on Use Target Duration and enter a duration in seconds.
  6. Activate Save Project Settings.

Import and edit a clip

  1. In the Project group, activate Import Clips.
  2. Select one or more video files and activate Open.
  3. Select an imported clip and choose Open Clip Editor from its Actions menu.
  4. Play the clip and set In and Out points as needed.
  5. Use Delete Selection, Trim Start to Playhead, or Trim End from Playhead to remove material.

Add the clip to the timeline

  1. Move the project playhead to the intended position.
  2. In the Clip Editor, activate Append to Timeline, Insert and Split, Insert and Overwrite, or an Insert on Top command.
  3. Return to the project Editor and play the assembled project.
  4. Repeat these steps for additional clips.

Export the movie

  1. To export part of the project, set both In and Out points in the project Editor.
  2. To export the complete project, clear both points.
  3. Choose File > Export Project or press Command-E.
  4. In the Export Project dialog, choose a filename, location, and format, then activate Export.
  5. Read Export progress in the progress dialog or activate Cancel Export to stop.
  6. When export finishes, read the system notification containing the exported filename.
