Use Trimato with VoiceOver

Move through a project

The project workspace contains Project, Editor, Timeline, and Inspector groups.

  • Use Project to import, organize, open, place, and relink source clips.
  • Use Editor for playback, project In and Out points, edit-point navigation, and blading.
  • Use Timeline to choose one track, then review, open, move, and delete its clips and transitions in order.
  • Use Inspector to read information about the selected item.

Edit from the Editor group

  1. Move VoiceOver to any control in Editor.
  2. Use Space, J, K, L, the Arrow keys, or the playback buttons.
  3. Use Command-Arrow keys to move among project edit points.
  4. Press Command-B to blade the clip beneath the playhead.

Work with timeline tracks

Choose a track with the Track picker or Command-Option-Up Arrow and Command-Option-Down Arrow. Interact with Timeline clips to move through that track in order. Focusing a clip or transition selects it and updates Inspector. Activate a clip to open Clip Editor, or activate a transition to edit it.

Check export progress

  1. Choose File > Export Project or press Command-E.
  2. In the Export Project dialog, choose the filename, location, and format, then activate Export.
  3. VoiceOver moves to Export progress in the progress dialog.
  4. Read the current percentage or activate Cancel Export to stop.

Use menus as a command reference

Use the Playback, Markers, Clip, and Timeline menus to review available commands and their shortcuts.
