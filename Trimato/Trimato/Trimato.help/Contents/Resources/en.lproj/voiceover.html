Trimato Help

Use Trimato with VoiceOver

Move through a project

The project workspace contains Project, Editor, and Timeline groups.

  • Use Project to import, organize, open, place, and relink source clips.
  • Use Editor for playback, project In and Out points, edit-point navigation, blading, transitions, and opening the clip at the playhead.
  • Use Timeline to choose one track, then review, open, move, and delete its clips and transitions in order.
  • Press Command-I to open Get Info for the focused source, Editor, timeline item, or Clip Editor item. VoiceOver starts on the item’s Info heading, and each field speaks its label with its value.

Edit from the Editor group

  1. Move VoiceOver to any control in Editor.
  2. Use Space, J, K, L, the Arrow keys, or the playback buttons.
  3. Use Command-Arrow keys to move among project edit points. Trimato announces whether each destination is a video edit point, an audio edit point, or both.
  4. Press Command-B to blade the clip beneath the playhead.
  5. Press Command-[ or Command-] to trim the announced active-track clip to the shared project playhead.
  6. On an additional track, press plain [ or ] to position the complete clip at the playhead without trimming its stored source.
  7. Press C to open Clip Editor for the active-track clip at or immediately after the playhead.
  8. Press Command-T, F, or X to add transitions without leaving Editor.

Work with timeline tracks

Choose a track with the Track picker or Command-Option-Up Arrow and Command-Option-Down Arrow. The shortcuts announce the selected track and its direct-edit clip. The direct-edit clip is remembered separately for each track. If none has been remembered, Trimato uses the incoming clip at an edit point, a clip containing the shared playhead, the next clip, or the last earlier clip. When you work directly in Timeline, move through the selected track in chronological order. The playhead clip is identified as Current clip. Focusing a clip or transition makes it the Get Info target; it does not pick up the clip. Activate a clip to open Clip Editor, or activate a transition to edit it.

Trim or position the announced clip

In Editor, press Command-[ to trim the announced clip's start to the shared project playhead, or Command-] to trim its end. A successful trim announces the clip, track, edge, and time. Plain [ and ] are different commands: on an additional track, they move the complete clip so its head or tail meets the playhead without trimming its stored source.

Select, open, and move timeline clips

In Timeline Clips, Enter or Return opens the focused clip in Clip Editor. Space picks up that clip; Space again drops it. On primary tracks, while a clip is selected for moving, Left Arrow or Up Arrow moves it one clip earlier and Right Arrow or Down Arrow moves it one clip later. Trimato announces positions only during pickup and movement. The list stays stable until you drop the clip. Escape also drops it, and Command-Z undoes the complete move. Turn Quick Nav off if it is using the plain arrow keys, or use the Move To… submenu for list ordering.

On additional video and audio tracks, Left Arrow or Up Arrow moves the focused clip one project frame earlier. Right Arrow or Down Arrow moves it one frame later. You do not need to pick it up first. Trimato announces the new start frame. A clip cannot move through another clip on the same track. Remove attached transitions before moving it.

Current means the clip under the project playhead. In a gap, no clip is Current. Selected means a clip picked up with Space. Moving with VO-Arrow changes neither state.

To place a clip at a specific destination, select the source for moving with Space, then focus the destination and open its context menu or Selected Element Actions. Choose Move To…, then Start, Before, After, or End. The source stays selected for moving while you navigate to the destination. Start and End also work on a focused clip without pickup. The context menu no longer has separate Move Earlier and Move Later items. The Timeline menu’s Move Clip Earlier and Move Clip Later commands remain available for a one-clip reorder on primary tracks or a one-frame nudge on additional tracks.

Command-C copies the focused clip. Command-V pastes a copy after the focused destination. Command-Option-V moves the movement selection, or the copied clip when none is selected for moving, after the destination. Outside Timeline Clips, macOS keeps standard Copy and Paste behavior.

For audio tracks, turn on Mute Track to silence that track in playback and export.

Check export progress

  1. Choose File > Export Project or press Command-E.
  2. In the Export Project dialog, choose the filename, location, and format, then activate Export.
  3. A progress bar will appear. Choose Cancel Export if you want to stop.

Use menus as a command reference

Use the Playback, Markers, Clip, and Timeline menus to review available commands and their shortcuts.

Inspect the video frame

The Editor exposes the displayed Video frame as an image immediately before the Project playhead slider. Its value gives the project time and frame number. Focusing this image does not play, seek, or select a clip. The image is omitted for audio-only projects and while preview is unavailable or preparing.

Press VO-Shift-L to request an image description from macOS.
