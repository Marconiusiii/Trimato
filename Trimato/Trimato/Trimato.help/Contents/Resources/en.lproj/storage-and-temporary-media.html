Storage and temporary media

Project files

A Trimato project stores editing choices and references to its audio and video sources. Keep those sources available for playback and export.

Use File > Consolidate Clips to gather media into the project’s Clips folder. Accepted recordings are stored in Recordings beside the project. Keep these folders with the project when moving it.

Choose how imported media is stored.

Playback proxies

Trimato uses original media for playback when supported by macOS. For other sources it creates a proxy, a compatible copy for preview and clip editing. Project export reads the original media.

Proxies are stored in macOS Caches and can be reused across sessions. A change to a source’s size or modification date causes its proxy to be rebuilt.

Frame indexes and waveforms

Completed frame indexes and waveforms are cached for reuse when the same media opens again. Changed sources are analyzed again.

Storage limits

The analysis and proxy cache has a 10 GB limit. Cleanup removes least recently used proxies, keeping those required by open projects or editors. Before creating a proxy, Trimato also checks for at least 10 GB of available disk space.

macOS can clear cached files when storage is low. Trimato recreates them from their original media when needed.

Review and clear the cache

  1. Choose Trimato > Settings > Storage.
  2. Read Storage used, Cache files, Storage limit, and Stored in.
  3. Choose Refresh storage usage to update the figures.

Clear cache not used recently removes analysis and proxies last used more than seven days ago. Clear all cached media removes analysis and unneeded proxies, keeping active preparation and proxies required by open projects or editors. Confirm the chosen cleanup.

Temporary renders

Transitions, filters, adjusted audio, and exports use temporary files separate from the media cache.

  • Replacing a project preview removes its previous render files.
  • Cancelling or failing a preview rebuild removes files created for that attempt.
  • Replacing or closing an adjusted-audio preview removes its temporary audio.
  • Closing a project removes the temporary files supporting its preview.
  • Finishing, cancelling, or failing an export removes its temporary files.

After an unexpected shutdown, later media preparation can remove render files from previous sessions once they are at least a day old. Files used by a running session are retained.
