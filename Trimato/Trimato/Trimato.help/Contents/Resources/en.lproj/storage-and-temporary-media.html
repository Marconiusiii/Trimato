Understand storage and temporary media

This page shows what Trimato stores and which files you can clear.

Know what a project saves

A Trimato project saves your editing choices and references to the original audio and video files. It does not copy those original files into the project.

Keep every original file available. A playback proxy or temporary render is not a backup and cannot replace a missing original during final export.

Use original media directly

Trimato uses an original file for playback when macOS can play it. The media cache can still contain frame indexes and audio waveforms for those files.

If the original can play but needs conversion for export, Trimato still uses the original while you edit and performs the required conversion during export.

Understand playback proxies

If macOS cannot play an original file directly, Trimato creates a playback proxy. A playback proxy is a compatible editing copy used for project preview and clip editing. It leaves the original unchanged.

Playback proxies are stored in macOS Caches and can be reused after a project closes. Trimato can recreate a missing or cleared proxy when the original file is available.

If the original file's size or modification date changes, Trimato stops using the old proxy and creates one that matches the changed original.

Trimato allows up to 10 GB for cached analysis and playback proxies. When the limit is exceeded, Trimato removes the least recently used proxies first. It also tries to keep at least 10 GB of disk space available before creating another proxy. Proxies being used by an open project or editor are retained.

macOS may remove cached files when storage is low. This is safe because Trimato can recreate them from the originals.

Reuse clip analysis

Trimato keeps completed video frame indexes and audio waveforms so reopening an unchanged clip does not repeat that analysis. Changed or replaced files are analyzed again. Cached analysis can also be reused after restarting Trimato.

Review media cache storage

  1. Choose Trimato > Settings.
  2. Move to Media cache storage.
  3. Read Storage used, Cache files, Storage limit, and Stored in.
  4. Activate Refresh storage usage when you want Trimato to read the folder again.

The reported size does not include projects, original media, completed exports, transition previews, audio previews, or files prepared for export.

Clear cached media

ControlResult
Clear cache not used recentlyRemoves cached analysis and playback proxies not used in the last seven days.
Clear all cached mediaRemoves cached analysis and unneeded proxies, keeping active preparation and proxies required by an open project or editor.

Both commands leave original media, projects, and completed exports unchanged. Trimato recreates cleared analysis or proxies when needed, provided the original remains available.

Understand temporary files

Transitions, filters, audio changes, and exports can create temporary files. These files do not count toward the media cache total.

Know when temporary files are removed

  • Rebuilding a project preview removes the files used by the previous preview.
  • Cancelling or failing a preview rebuild removes the new files created by that attempt.
  • Replacing or closing an adjusted-audio preview removes its temporary audio file.
  • Closing a project normally removes the transition, effect, and conversion files supporting its preview.
  • Finishing, cancelling, or failing an export removes the temporary files created for that export.

After an unexpected shutdown

If Trimato or macOS closes unexpectedly, macOS can remove files from the temporary folder later. Trimato removes older unfinished export files when it prepares another export.

Generated and filtered media

Generated items and filters can use additional temporary space. Their files are not included in the media cache total.
