Trimato Manual contents.

Audio settings

Choose Trimato > Settings, then Audio.

Microphone access

Check Microphone access before recording. Choose Allow microphone access to respond to the macOS permission request. Use Microphone privacy settings to change an existing permission in System Settings.

Recording input

Choose Microphone to select an input device. System Default follows the current macOS input. Choose Microphone channel for a device with multiple input channels.

Choose Standard recording quality for 16-bit audio or High for 24-bit audio. Recordings use the selected input's sample rate.

Adjust Microphone volume when the device provides an adjustable input level. Some devices require their own hardware controls.

Playback output

Choose Playback device to select the output for Trimato audio. System Default follows the current macOS output. The input and output can be different devices.

Test recording

  1. Turn on Record Test and speak into the selected microphone.
  2. Turn off Record Test to finish.
  3. Read Status, Length, and Recording level. If the level is Too loud, lower the microphone volume and record another test.
  4. Turn on Play Test to listen. Turn it off to stop playback.
  5. Choose Delete Test to remove the test recording.
