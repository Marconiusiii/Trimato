Storage settings

Choose Trimato > Settings, then Storage.

Media cache storage

Read Storage used, Cache files, Storage limit, and Stored in to review Trimato's media cache. Choose Refresh storage usage to update these figures.

Trimato caches video frame indexes, audio waveforms, and playback proxies so unchanged media can reopen without repeating preparation. Playback proxies are compatible editing copies used when an original needs one. The cache is stored in macOS Caches and has a 10 GB limit.

The reported total excludes projects, original media, exports, transition renders, audio previews, and export intermediates.

Clear cached media

  • Clear cache not used recently removes cached analysis and playback proxies not used in the last seven days.
  • Clear all cached media removes cached analysis and unneeded playback proxies. Active preparation and proxies required by an open project or editor are kept.

Review the confirmation before clearing the cache. These commands do not remove original media or Trimato projects. Cleared analysis and proxies can be recreated when the original media is available.
